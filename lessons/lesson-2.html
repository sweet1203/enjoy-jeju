튜링 자료집 data.json 만들기

인공지능 기초 · 2. 인공지능과 학습

오늘의 학습 목표

  1. 페르소나에 필요한 자료를 선정하고 출처를 확인하여 수집할 수 있다.
  2. 수집한 자료를 id, content, keywords 구조의 JSON으로 정리할 수 있다.
  3. 검색이 잘 되도록 자료마다 핵심 키워드를 뽑을 수 있다.

개념오늘 알아 둘 것

JSON · {"이름": 값} 모양으로 자료를 정리하는 형식이에요. 파이썬 딕셔너리와 거의 똑같아요.
app.py가 읽는 구조 · documents 목록 안에 문서마다 id(번호) · content(사실) · keywords(검색어)가 들어 있어요.
좋은 자료의 조건 · ① 한 문서에 한 주제(날짜·장소·인물을 분명하게) ② 3인칭 서술 ③ 학생이 물을 법한 키워드

실제 data.json의 문서 한 건

{ "documents": [ { "id": "T09", "content": "장거리 달리기를 즐겼다. 마라톤 기록은 약 2시간 46분이었고, 1948년 올림픽 대표 선발에 도전했지만 부상으로 뜻을 이루지 못했다.", "keywords": ["운동", "달리기", "마라톤", "육상", "올림픽", "취미", "체력", "건강", "기록"] } ] }
JSON 문법, 이것만 기억하세요
  • { } 중괄호 = 하나의 묶음(문서 한 건), [ ] 대괄호 = 여러 개의 목록
  • 이름과 글자는 반드시 큰따옴표 " "로 감싸요. 작은따옴표 ' '는 오류!
  • 항목 사이에는 쉼표 ,를 넣고, 마지막 항목 뒤에는 쉼표를 넣지 않아요.
  • 열었던 괄호는 꼭 닫아요. { 개수 = } 개수
// ✘ 자주 하는 실수 { 'id': "T20", "content": "...", "keywords": ["a", "b",] } // ↑ 작은따옴표 ↑ 마지막 쉼표
왜 ‘그는 ~했다’처럼 3인칭으로 쓰나요?

app.py는 찾은 자료를 튜링에게 건네면서 “자료의 ‘그’는 나 자신이다”라고 알려 줘요. 그래서 3인칭으로 써 두면 튜링이 자기 이야기로 자연스럽게 바꿔 말해요.

“나는 ~했다”로 쓰면 학생의 이야기인지 튜링의 이야기인지 헷갈릴 수 있어요.

keywords는 어디에 쓰이나요?

keywords는 자료를 찾을 때만 쓰여요. AI에게 건네지는 건 content뿐이에요.

예를 들어 학생이 “선생님 운동 좋아하세요?”라고 물으면, content에는 ‘운동’이라는 말이 없어도 keywords의 ‘운동’ 덕분에 T09를 찾을 수 있어요. 그러니 학생들이 실제로 쓸 법한 말을 넣는 게 중요해요.
