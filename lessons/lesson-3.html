BM25 검색은 어떻게 자료를 고르나요?

질문과 자료를 작은 조각으로 자른 뒤, 겹치는 조각이 많을수록 높은 점수를 줘요. 그리고 여러 자료에 흔하게 나오는 조각보다 드물게 나오는 조각이 겹칠 때 점수를 더 많이 줘요.

app.py는 그중 점수가 가장 높은 1건만 골라요(k=1). 겹치는 조각이 하나도 없으면(점수 0) 자료를 넣지 않아요.

이렇게 ‘단서(겹치는 조각)를 이용해 가능성이 높은 것부터 찾는 방식’이 인공지능 기초의 정보 이용 탐색이에요. 모든 자료를 처음부터 끝까지 읽는 방식은 맹목적 탐색이라고 해요.

왜 낱말을 2글자씩 자르나요? (tokenize)

한국어는 같은 낱말에 조사가 다르게 붙어요. ‘자전거로’, ‘자전거를’, ‘자전거가’… 통째로 비교하면 서로 다른 말로 보이죠.

2글자씩 자르면 ‘자전’, ‘전거’가 모두 겹쳐서 조사가 달라도 찾을 수 있어요. 예: 모방게임 → 모방 · 방게 · 게임

직접 해 보기 · 질문을 쓰면 app.py와 같은 규칙으로 잘라 줘요. 자료 문장도 쓰면 겹치는 조각이 표시돼요.

질문을 왜 두 번 넣나요? 서버는 또 뭔가요?

app.py는 검색할 때 지금 질문 + 지금 질문 + 직전 질문을 써요. 지금 질문을 두 번 넣어 더 중요하게 보고, 직전 질문으로 앞의 주제도 이어 가요. “그럼 그때는요?”처럼 짧은 질문도 앞 맥락으로 찾을 수 있게요.

서버는 AI 모델(EXAONE)을 켜 두고 질문을 받으면 답을 돌려주는 컴퓨터예요. 선생님이 VESSL의 GPU 컴퓨터에서 vLLM이라는 프로그램으로 켜 둬요. 우리가 쓰는 app.py는 그 서버에 질문을 보내는 쪽(클라이언트)이에요.

AI가 답을 만드는 데 몇 초 걸려요. 서버가 바쁘면 질문을 차례로 처리해서 더 늦어질 수 있으니, 답이 나올 때까지 기다렸다가 다음 질문을 해요.

도전: 2글자 대신 3글자로 자르면?

tokenize 함수의 2를 3으로 바꿔 보세요. 그런데 그냥 바꾸면 2글자짜리 낱말(예: ‘학교’, ‘수학’)이 사라지는 문제가 생겨요. 왜 그럴까요? 고쳐 보세요.

for word in words: if len(word) == 1: # ← 힌트: 이 조건을 어떻게 바꿔야 할까? tokens.append(word) else: for index in range(len(word) - 1): # ← 3글자로 자르려면? token = word[index:index + 2] # ← 3글자로 자르려면? tokens.append(token)
정답 예시 보기
for word in words: if len(word) <= 3: # 3글자 이하는 통째로 넣는다 tokens.append(word) else: for index in range(len(word) - 2): token = word[index:index + 3] tokens.append(token)

range(len(word) - 2)는 ‘학교’(2글자)에서 range(0)이 되어 조각이 하나도 안 나와요. 그래서 짧은 낱말은 따로 처리해야 해요.
