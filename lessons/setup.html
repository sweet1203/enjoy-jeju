튜링 실행 따라하기 카드

내 컴퓨터에서 VESSL 작업공간을 열고, 튜링 프로그램(app.py)을 실행하는 방법

먼저 알아 둘 것

설치할 프로그램은 없어요. 튜링 프로그램과 AI 모델은 인터넷 너머의 GPU 컴퓨터(VESSL 작업공간)에 들어 있고, 우리는 크롬 브라우저로 각자 로그인해서 그 컴퓨터를 써요.

1차시 끝①② 로그인하고 작업공간 열어 보기
2차시 끝③ 우리 data.json 올리기
3차시 도입④ 터미널에서 튜링 실행하기
3차시 정리 · 4차시⑤ 고치고 다시 실행하기

준비물

  • 학교 컴퓨터의 크롬 브라우저
  • 내 VESSL 계정 (가입한 이메일과 비밀번호)
  • 선생님이 알려 준 수업 조직(Organization) 이름과 작업공간(Workspace) 이름
우리 반 조직 이름 / 작업공간 이름 (선생님이 알려 준 대로 적기)

①VESSL 로그인 1차시

  1. VESSL 접속크롬 주소창에 vessl.ai를 입력하고 오른쪽 위 Log in을 눌러요.
  2. 로그인내 이메일과 비밀번호로 로그인해요. 처음이라면 선생님이 보낸 초대 메일의 링크를 먼저 눌러 수업 조직에 들어가요.
  3. 수업 조직 고르기왼쪽 위 조직 이름을 눌러 선생님이 알려 준 조직으로 바꿔요. 다른 조직에 있으면 작업공간이 보이지 않아요.

②작업공간 열기 1차시

  1. Workspaces 메뉴왼쪽 메뉴의 Workspaces에서 내 작업공간을 찾아요.
  2. 상태 확인상태가 Running이면 다음으로! Stopped라면 Start를 누르고 Running이 될 때까지 기다려요(몇 분 걸릴 수 있어요).
  3. JupyterLab 열기작업공간 이름을 누른 뒤 JupyterLab 버튼을 눌러요. 새 탭에 JupyterLab 화면이 열려요.
  4. 폴더 확인왼쪽 파일 목록에 persona-core 폴더가 보이면 준비 끝! 그 안에 app.py와 data.json이 있어요.

작업공간을 다 쓰고 나면 선생님 안내에 따라 Stop을 눌러 꺼 둬요. 켜 두면 GPU가 계속 쓰여요.

③우리 data.json 올리기 2차시

  1. 원본 복사해 두기persona-core 폴더의 data.json을 오른쪽 클릭 → Duplicate. 생긴 파일 이름을 data_backup.json으로 바꿔요. 실수해도 되돌릴 수 있어요.
  2. data.json 열기data.json을 더블클릭해서 열어요.
  3. 바꿔 넣기2차시 학습지 JSON 형식 검사기를 통과한 모둠 data.json 전체를 복사해서, 열린 파일의 내용을 모두 지우고(Ctrl+A → Delete) 붙여 넣어요.
  4. 저장Ctrl+S. 탭 이름 옆의 ● 표시가 사라지면 저장된 거예요.

④터미널에서 튜링 실행하기 3차시

  1. 터미널 열기JupyterLab 위 메뉴 File → New → Terminal (또는 Launcher 화면의 Terminal 아이콘).
  2. 위치 확인아래 명령을 치고 Enter. 목록에 persona-core가 보이면 맞는 곳이에요.
    ls
  3. 튜링 실행아래 명령을 그대로 쳐요.
    python persona-core/app.py
    시작 안내와 튜링의 첫인사가 나오면 성공! 내 이름을 소개하며 대화를 시작해요.
  4. 끝내기대화를 마치려면 Ctrl+C.

답이 바로 안 나와도 괜찮아요. AI가 답을 만드는 데 몇 초 걸려요. 같은 서버를 여러 명이 쓰면 차례로 처리해서 더 늦어질 수 있어요.

⑤고치고 다시 실행하기 3차시 정리 · 4차시

  1. 파일 열기왼쪽 목록에서 persona-core/app.py(또는 data.json)을 더블클릭해요.
  2. 고치기연습: OPENING = "..." 줄의 따옴표 안 문장만 우리 모둠 인사로 바꿔요. 따옴표는 지우지 않아요.
  3. 저장Ctrl+S
  4. 다시 실행터미널에서 Ctrl+C로 끝내고, ↑ 키를 누르면 방금 친 명령이 다시 나와요. Enter!
  5. 확인튜링의 첫인사가 바뀌었으면 성공. 4차시에는 같은 방법으로 data.json과 SYSTEM_PROMPT를 고쳐요.

💡 고친 내용은 다시 실행해야 반영돼요. 저장만 하고 실행 중인 대화에 계속 물으면 예전 내용으로 답해요.
