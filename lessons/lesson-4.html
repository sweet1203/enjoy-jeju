오늘의 학습 목표

  1. 페르소나 AI의 답변에서 환각을 찾아 근거 자료와 비교해 원인을 분석할 수 있다.
  2. 평가 결과를 반영해 data.json과 app.py의 프롬프트를 고치고 성능을 개선할 수 있다.
  3. 실존 인물을 흉내 내는 AI의 윤리적 문제를 설명할 수 있다.

환각을 줄이는 방법 · ① 자료 보강(RAG): data.json에 근거 자료 추가·수정 → app.py가 검색 ② 규칙 추가: “자료에 없는 내용은 모른다고 답한다” ③ 말투·성격 설정 다듬기
AI는 왜 모르는 것도 그럴듯하게 말할까요?

언어 모델은 ‘정답을 아는’ 것이 아니라, 지금까지의 글 다음에 가장 그럴듯한 단어를 하나씩 이어 붙여 문장을 만들어요. 휴대폰 자판의 다음 단어 추천이 아주 똑똑해진 것과 비슷해요.

그래서 자료에 없는 질문을 받아도 문장은 매끄럽게 만들어 내요. 매끄럽다고 사실인 건 아니에요!

선택 심화자동 검증 프로그램 eval.py 만들기 (3단계)

1단계의 질문 10개를 손으로 하나씩 묻는 대신, 반복문으로 자동으로 묻고 결과를 표(CSV)로 저장하는 프로그램을 만들어요. 고1 정보에서 배운 반복문 · 리스트 · 파일 저장이 그대로 쓰여요.

준비물

  • eval_starter.py — 빈칸 ①~⑤를 채우는 학생용
  • questions.csv — 검증 질문 틀 (우리 모둠 질문으로 바꾸기)
  • eval.py — 완성본 (막히면 참고, 교사용)

    
파일 이름을 누르면 내용이 펼쳐져요. 내 작업공간의 persona-core 폴더(app.py와 같은 곳)에 같은 이름으로 새 파일을 만들고 붙여 넣어요.


    

      
순서실행하고 비교하기

      
# ① 모델 없이 검색만 확인 (빠름, 서버를 쓰지 않음)
python persona-core/eval_starter.py --dry-run

# ② 수정 전: 튜링에게 질문하고 결과 저장
python persona-core/eval_starter.py --out persona-core/before.csv

# ③ data.json 이나 SYSTEM_PROMPT 를 고친 뒤 다시 실행
python persona-core/eval_starter.py --out persona-core/after.csv

      
before.csv와 after.csv를 열어 ‘판정’ 칸(정확 / 사실 오류 / 지어낸 답 / 어색한 말투)을 채우고, 위 4단계 정답률 표에 옮겨 적어요.

왜 질문을 하나씩 차례로 보내나요?

      
우리 수업의 모델 서버는 한 번에 한 질문만 처리하도록 설정돼 있어요. 반복문은 앞 질문의 답을 받은 뒤에 다음 질문을 보내니까, 손으로 순서를 정할 필요가 없어요.
