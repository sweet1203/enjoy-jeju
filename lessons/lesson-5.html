오늘의 학습 목표

  1. 완성한 페르소나를 웹 채팅이나 Roblox NPC로 연결하여 실행할 수 있다.
  2. 평가 기준에 따라 다른 모둠의 페르소나를 평가하고 피드백할 수 있다.
  3. 비판적 자세로 인간과 AI의 공존 방안을 제시할 수 있다.

개념오늘 알아 둘 것

하나의 두뇌, 여러 개의 창 · 웹 채팅 서버와 Roblox 서버도 app.py의 SYSTEM_PROMPT와 검색 기능을 그대로 가져다 써요. 그래서 4차시에 고친 내용이 웹과 Roblox에도 똑같이 반영돼요.
웹 채팅 · VESSL이 만들어 준 공개 주소로 브라우저에서 접속해요. 주소 뒤에 /ready를 붙여 준비 상태를 확인해요.
Roblox 연결 · ① VESSL에서 Roblox용 API 서버 실행(포트 7860) ② Roblox Studio 프로젝트에 서버 주소 입력 ③ 게임 서버 코드(Luau)가 API를 불러 NPC가 답변
서버, 클라이언트, API가 헷갈려요

식당에 비유해 볼게요. 주방(서버)에서는 요리사(EXAONE 모델)가 요리를 해요. 손님 자리(클라이언트)는 터미널, 웹 화면, Roblox 게임이에요. 손님은 주방에 직접 들어가지 않고 주문서(API)로 주문하고 음식을 받아요.

그래서 화면이 셋이어도 요리사는 한 명이고, 레시피(app.py의 SYSTEM_PROMPT와 data.json)도 하나예요.

포트 7860, /ready는 뭔가요?

포트는 한 컴퓨터 안의 ‘문 번호’예요. 모델 서버는 8000번 문, 웹·Roblox 서버는 7860번 문에서 손님을 받아요.

공개 주소 뒤에 /ready를 붙여 열었을 때 {"ready": true}가 보이면 모델까지 연결 준비가 끝난 거예요.

Luau는 어떤 언어예요?

Roblox 게임 안에서 돌아가는 프로그래밍 언어예요. 파이썬처럼 읽기 쉬운 편이에요. 우리 프로젝트에서는 플레이어가 쓴 말을 VESSL 서버로 보내고, 받은 답을 NPC 말풍선으로 보여 주는 일을 해요.
