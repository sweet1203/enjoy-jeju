💻 선택 심화 · 코드 작성 단계

기본 수업(프롬프트 · data.json 작성)은 모두 함께 하고, 코드를 더 다뤄 보고 싶은 학생이나 모둠만 아래 단계를 골라 이어 갑니다. 모두 3차시에 익힌 대로 내 작업공간의 터미널에서 고치고 다시 실행해요. 고치기 전에 원본 파일을 Duplicate 해 두세요.

단계학생이 하는 일교사가 미리 줄 것차시
1. 값 바꾸기OPENING, 검색 개수 k, temperature, 대화 기억 길이를 바꿔 보고 같은 질문의 답 비교바꿀 곳을 표시한 app.py, 관찰 기록표3
2. 함수 고치기검색 점수를 print로 출력, tokenize를 3글자 자르기로 고쳐 점수 변화 확인빈칸 · 힌트가 있는 코드 조각3
3. 새 코드 쓰기eval_starter.py의 빈칸 5개를 채워 자동 검증 프로그램 완성 → 수정 전 · 후 비교 4

운영 팁 eval.py --dry-run은 모델을 부르지 않고 검색만 확인해서 빠르게 돌아가요. 모델 서버가 바쁠 때는 dry-run으로 먼저 확인하고, 답이 필요한 비교는 질문 10개를 한 번에 돌려 결과 CSV로 봅니다.

🏫 트랙 1. 중학생이 만나는 ‘튜링 카드’ AI

대상 · 과목
중학교 2~3학년 · 2022 개정 「정보」 (인공지능 · 디지털 문화 영역), 「도덕」 연계
차시
4차시 (고등학교 5차시에서 코드 · 터미널 단계를 빼고 체험과 판단 중심으로 재구성)
핵심 아이디어
학생은 코드도, 서버 주소도 다루지 않는다. 손으로 인물 카드(말투 · 모르는 것 · 답하지 않을 것)와 사실 카드(자료)를 만들고, AI와의 대화는 교사 화면 하나를 반 전체가 함께 보며 한다.

왜 교사 화면 하나로? 튜링 AI는 VESSL 작업공간 안에서 돌아가서, 주소만 나눠 준다고 열리지 않고 학생마다 VESSL 계정으로 로그인해야 해요(고등학교 수업 방식). 중학생은 만 14세 미만이 있어 계정을 만들려면 보호자 동의가 필요합니다. 그래서 중학교에서는 교사가 실행하고 학생은 질문과 판단을 맡는 방식으로 바꿨어요. 학생 기기가 없어도 종이 카드로 모두 진행할 수 있습니다.

1누가 AI일까? 모둠이 튜링에게 묻고 싶은 질문을 쪽지에 쓴다 → 화면에 뜬 답 A · B · C (친구 답, 선생님 답, AI 답) 중 AI를 골라 이유를 적는다 → 인공지능의 뜻과 특징 정리쉬는 시간에 받은 질문 2~3개를 튜링 AI에 넣고, 사람 답과 섞어 화면에 띄움[9정04-01] 인공지능의 개념과 특성을 설명하고 인공지능 소프트웨어를 구별한다.
2튜링 카드 만들기 인물 카드 1장(시대 · 말투 · 모르는 것 · 답하지 않을 것)과 사실 카드 5장(한 문장 사실 + 출처 + 찾을 낱말)을 쓴다카드를 걷어 수업 후 모둠별 data_모둠명.json으로 저장 (웹 학습지를 쓰면 붙여 넣기만)[9정04-02] 인공지능 학습에서 데이터의 중요성을 이해하고, 필요한 데이터를 수집하여 분류한다.
3① ‘사람 튜링’ 놀이 모둠원 1명이 사실 카드만 보고 답하고, 나머지가 질문한다. 카드에 없는 걸 물으면 어떻게 될까?
② 우리 튜링과 대화 모둠 대표가 교사 화면에서 질문 카드 2~3장을 입력하고, 나머지는 ○×를 기록한다. 같은 질문을 ‘기본 자료’ 튜링에게도 해서 비교한다		모둠 차례마다 data.json을 그 모둠 파일로 바꾸고 app.py를 다시 실행 (10초 안팎). 모델 서버는 켠 그대로 둠[9정04-03] 다양한 데이터를 활용하여 인공지능 시스템을 구성하고 적용한다.
4틀린 답 고치기와 약속 × 표시한 답의 원인을 찾는다 (카드에 없었나? 카드가 틀렸나?) → 카드를 고쳐 다시 확인 → 출처 · 사생활 보호를 담은 ‘인물 AI 사용 약속’ 3가지고친 카드를 반영해 같은 질문을 다시 보여 줌[9정04-05] 데이터의 수집과 활용에서 발생하는 윤리적인 문제의 해결 방안을 구상한다.
[9정05-03] 개인 정보 및 권리와 저작권 보호 실천

운영 팁 학생 기기에는 설치하거나 접속할 것이 없습니다. 3차시는 한 모둠이 교사 화면을 쓰는 동안 다른 모둠은 ‘사람 튜링’ 놀이를 하도록 짜면 기다리는 시간이 없어요. 실존 인물의 사생활 질문에는 답하지 않는 규칙을 꼭 함께 안내하세요.
