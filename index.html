왜 이 수업인가요?

“기계는 생각할 수 있는가?” 1950년, 이 질문을 처음 던진 사람이 컴퓨터 과학과 AI의 아버지 앨런 튜링입니다. 학생들은 튜링의 생각과 말투를 담은 페르소나 AI를 직접 만들고 대화하면서, AI의 출발점이 된 이 질문을 다시 던지고 튜링 테스트처럼 ‘AI다움’과 ‘사람다움’의 경계를 스스로 따져 봅니다.

💻 선택 심화 · 코드 작성 단계

기본 수업(프롬프트 · data.json 작성)은 그대로 진행하고, 코드를 더 다뤄 보고 싶은 모둠은 아래 단계로 넓혀 갑니다. 각 단계는 해당 차시 학습지 아래쪽 ‘선택 심화’ 칸에 있어요.

단계학생이 하는 일교사가 미리 제공할 것차시
0. 설정SYSTEM_PROMPT와 data.json 작성 (기본 수업)켜 둔 모델 서버, 모둠별 app.py 사본1~2
1. 값 바꾸기OPENING, 검색 개수 k, temperature, 대화 기억 길이를 바꿔 보고 답 비교바꿀 곳을 표시한 app.py, 관찰 기록표3
2. 함수 고치기검색 점수를 print로 출력, tokenize를 3글자 자르기로 고치기빈칸 · 힌트가 있는 코드 조각3
3. 새 코드 쓰기검증 질문을 반복문으로 자동 질문하고 CSV로 저장하는 eval.py 완성 → 수정 전 · 후 비교eval_starter.py (빈칸 5개) · questions.csv · eval.py (완성본)4

운영 전 확인 모둠마다 app.py를 실행하려면 VESSL JupyterLab 터미널을 모둠별로 열거나 교사 화면에서 차례로 실행합니다. 지금 서버 설정(--max-num-seqs 1)은 한 번에 한 질문만 받으므로, 여러 모둠이 동시에 쓰려면 이 값을 늘리고 GPU 메모리가 버티는지 미리 시험해 보세요. eval.py --dry-run은 모델 서버 없이 검색만 확인하므로 서버를 기다리는 동안 먼저 해 볼 수 있어요.

대상 · 과목

핵심 아이디어
학생은 코드를 다루지 않고 인물 카드(말투·모르는 것·대답하지 않을 것)와 사실 카드(자료)를 만든다. 교사가 미리 켜 둔 웹 채팅에 카드를 넣어 대화하고, 틀린 답을 찾아 고친다.

차시활동성취기준

4틀린 답 고치기와 약속 ○× 기록으로 지어낸 답 찾기 → 카드 고치기, 출처 · 사생활 보호를 담은 ‘인물 AI 사용 약속’ 3가지[9정04-05] 데이터의 수집과 활용에서 발생하는 윤리적인 문제의 해결 방안을 구상한다.
[9정05-03] 개인 정보 및 권리와 저작권 보호 실천

운영 팁 웹 채팅 서버는 교사가 VESSL에서 한 번만 켜고, 모둠별 카드는 교사가 모아 서버에 반영합니다. 학생 기기에는 설치할 것이 없습니다. 실존 인물의 사생활 질문에는 답하지 않는 규칙을 꼭 함께 안내하세요.

🎯 미션 고르기 (모둠별 2~3개)

미션난이도할 일고칠 곳성공 기준
1. 명령어 만들기★/자료를 치면 마지막 참고 자료를, /처음을 치면 대화를 처음부터chat()의 while 반복문 맨 앞명령어는 모델에게 보내지 않고 바로 처리된다
2. 출처 밝히기★★답 뒤에 (참고: T09)처럼 쓴 자료 번호 표시, 시작할 때 ‘AI임을 알리는 안내 문구’ 출력print(f"튜링: …") 줄, WELCOME 뒤답마다 자료 번호 또는 ‘참고 자료 없음’이 보인다
3. 대화 기록 저장★★질문 · 참고 자료 · 답을 chat_log.csv에 한 줄씩 저장새 함수 save_log() 추가엑셀로 열어 4차시 환각 기록표에 바로 쓸 수 있다
4. ‘모른다’ 안전장치★★자료가 검색되지 않으면 “사실을 묻는 질문이면 지어내지 말라”는 안내를 함께 전달if len(evidence_parts) == 0: 부분자료 밖 질문에서 지어낸 답이 줄어든다 (eval.py로 전 · 후 비교)
5. 동의어 사전★★★“AI → 인공지능”, “튜링 테스트 → 모방 게임”처럼 학생 말을 자료의 말로 넓혀 검색새 함수 expand_query(), query 만드는 줄빗나가던 질문이 맞는 자료를 찾는다 (--dry-run으로 확인)
6. 코드로 막는 질문★★★개인정보 같은 금지어가 있으면 모델에 보내지 않고 정해진 문장으로 답하기while 반복문, 새 목록 BLOCK_WORDS프롬프트 규칙과 코드 규칙의 차이를 설명할 수 있다
